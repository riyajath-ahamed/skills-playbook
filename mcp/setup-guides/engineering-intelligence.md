# Status

No Engineering Intelligence MCP server is published or implemented.

The future tools should expose the same discovery, policy, and run operations as the `ei` CLI. They should read `skills/`, `workflows/`, and `mcp/catalog.yaml` rather than a second registry.

Until that server exists, use `ei` locally. Do not add a client configuration that points at a placeholder URL.

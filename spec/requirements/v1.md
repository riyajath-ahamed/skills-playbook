# Included

- Root instructions, standards, templates, and contributor guide.
- The initial skill set and seven workflows.
- MCP catalog, three profiles, and setup notes that cite official providers.
- Validators for skills, catalog, links, and evaluation-case structure.
- A rebuildable local index.
- `ei version`, `ei doctor`, `ei skills`, `ei workflows`, `ei mcp list`, `ei mcp health`, `ei knowledge search`, and `ei validate`.
- Run-state transitions and policy decisions covered by tests.
- GitHub Actions that validate the repository without secrets.

# Excluded

- Model calls, MCP sessions, and multi-agent execution.
- PostgreSQL, migrations that are applied, and a vector index.
- A web console and a public HTTP API.
- Deployment to a shared environment.
- A claim that any MCP server is installed or healthy.

# Acceptance

- `make validate` exits 0 on a machine with Python 3, PyYAML, and Go.
- `go test ./...` and `go vet ./...` pass in `platform/`.
- Optional tools that are absent are reported as absent by `ei doctor`.
